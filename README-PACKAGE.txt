This archive contains the current LOCAL student application (cvu-build) and staff application (staff_system), including vendor dependencies, assets, migrations and seeders.

Latest local camera and responsive changes are included. They have not been deployed or fully verified on real devices. This is not a fresh backup of Hostinger or its live database.

Credentials, .env files, database dumps, SQLite data, private uploaded documents, runtime caches/logs/sessions and redundant backup applications are excluded. Configure each application from its .env.example and use the intended shared database. Back up any existing database before running migrations; do not use migrate:fresh against existing data.

Each application's public directory is its web document root. See the included application READMEs for setup details.
